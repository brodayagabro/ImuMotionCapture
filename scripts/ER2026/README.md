# ER2026 — сравнение двух костюмов

Семафорный эксперимент с собственным костюмом ESP32/IMU и Noitom:
калибровка по пяти позам, демонстрация наборов слов, парная запись движений,
экспорт синхронных BVH и таблица записей.

Это отдельное приложение для экспериментов конференции ER2026. Основной
визуализатор запускается через `python -m pyqt_mocap` и не импортирует код
конференции. Эксперимент использует общие приём UDP, математику и OpenGL,
а собственный мастер калибровки хранится в `experiments/semaphore/guided_dialog.py`.

Настройки GUI разделены: основной визуализатор использует QSettings
`Neuromorph/MPU UDP Viewer Guided`, эксперимент — `Neuromorph/MPU UDP Viewer ER2026`.
Первый запуск эксперимента использует настройки по умолчанию; прежние настройки
основного приложения сохраняются. Локальные настройки и профили не включаются
в коммиты. Материалы `presentation_er2026/` также исключены из Git.

## Запуск

Из корня репозитория:

```powershell
.venv\Scripts\python.exe scripts\ER2026\main.py
```

Также доступен `python -m scripts.ER2026`. Для проверки интерфейса без Noitom
можно добавить `--fake`; запись при этом всё равно требует поток ESP32.
В окне захвата нажмите «Эксперимент…», чтобы открыть окно оператора.

Отдельный демонстратор:

```powershell
.venv\Scripts\python.exe -m scripts.ER2026.experiments.semaphore.main
```

Его режим `--debug` позволяет проверить показ слов без подключения костюмов.
Основной `main.py` можно запускать по абсолютному пути из любой рабочей папки;
место сохранения данных от текущей папки не зависит.

## Содержимое

```text
ER2026/
  main.py                       — единый запуск приложения
  paths.py                      — общие пути эксперимента
  noitom_comparison/             — приём двух потоков, отображение, парный BVH
  experiments/semaphore/        — калибровка, наборы слов, окна эксперимента
  diagnostics/orientation/      — анализ калибровки и записанных ориентаций
  records/                      — пользовательские записи и records.csv
  output/                       — отчёты, профили и архивные результаты проверок
```

Тесты и документация расположены рядом с соответствующими модулями.
Общие компоненты визуализатора и математики остаются в `host/`; внешний
SDK Noitom — в `scripts/MocapApi`. Конфигурация автоматически находит этот SDK.

## Записи

Новый путь по умолчанию — `scripts/ER2026/records/`. Сюда перенесена прежняя
папка `records` целиком, включая `records.csv`, журнал и архивный `semaphore`.
Относительные пути в таблице остаются действительными. Содержимое исторических
файлов не переписывалось; старые абсолютные пути внутри журналов относятся
к прежнему расположению. Контрольные суммы переноса сохранены в
`output/migration_records_manifest.json`.

`records/`, `recordings/` и `output/` внутри ER2026 исключены из Git.
Параметр `--records-dir` позволяет явно выбрать другое место сохранения.
