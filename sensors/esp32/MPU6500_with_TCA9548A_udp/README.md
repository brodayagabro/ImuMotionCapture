# ESP32: MPU6500 ×5 через TCA9548A и UDP

Это отдельный вариант основной прошивки для модулей MPU-6500, у которых
регистр `WHO_AM_I` (`0x75`) возвращает `0x70`. Сам датчик при этом
остаётся I2C-устройством с адресом `0x68`; I2C-адрес `0x70` принадлежит
мультиплексору TCA9548A.

UDP-протокол и команды намеренно совпадают с вариантом MPU-6050, поэтому
менять программу захвата и визуализации на компьютере не требуется. Для
настоящего MPU-6050 с `WHO_AM_I=0x68` используйте соседнюю прошивку
`DMP_with_TCA9548A_udp`.

## Файлы

- `MPU6500_with_TCA9548A_udp.ino` — работа с TCA9548A, регистрами
  MPU-6500, Wi-Fi, UDP, командами и сохранением калибровки;
- `MahonyFilter.h` и `MahonyFilter.cpp` — отдельная реализация
  шестикоординатного фильтра ориентации;
- `wifi_secrets.example.h` — безопасный шаблон настроек Wi-Fi;
- `wifi_secrets.h` — локальные реквизиты сети, исключённые из Git.

Прошивка не использует MPU6050 MotionApps, DMP и FIFO. Акселерометр и гироскоп
MPU-6500 читаются напрямую, а кватернион вычисляется в `MahonyFilter`.

## Аппаратная конфигурация

К ESP32-C3/C6 подключён TCA9548A, а к его каналам — до пяти MPU-6500.
Прошивка:

- ищет мультиплексор в диапазоне I2C-адресов `0x70`–`0x77`;
- ищет датчик по I2C-адресу `0x68` на каждом канале;
- принимает только `WHO_AM_I=0x70`;
- использует диапазоны ±2 g и ±250 °/с;
- опрашивает датчики и обновляет фильтры с частотой 100 Гц;
- отправляет кадры с настраиваемой частотой 1–100 Гц.

Идентификатор датчика в UDP-пакете равен физическому каналу TCA9548A.

| Канал TCA | Сегмент тела | Имя сегмента |
|---:|---|---|
| 7 | левое плечо / верхняя часть руки | `shoulder.L` |
| 6 | левое предплечье | `forearm.L` |
| 2 | корпус / спина | `spine` |
| 1 | правое предплечье | `forearm.R` |
| 0 | правое плечо / верхняя часть руки | `shoulder.R` |

По умолчанию прошивка автоматически сканирует все восемь каналов. При
`AUTO_DETECT_CHANNELS=false` используется список `0, 1, 2, 6, 7`.

## Настройка Wi-Fi

Перед первой сборкой создайте локальный файл настроек:

```bash
cd sensors/esp32/MPU6500_with_TCA9548A_udp
cp wifi_secrets.example.h wifi_secrets.h
```

Укажите в нём реквизиты сети:

```cpp
static const char *WIFI_SSID = "имя сети";
static const char *WIFI_PASSWORD = "пароль сети";
```

`wifi_secrets.h` игнорируется Git. UDP-сервер слушает порт `4210`, а
получателем потока становится отправитель последней корректной UDP-команды.

## Зависимости и сборка

Нужен только ESP32 Arduino core. `Wire`, `WiFi`, `Preferences` и
`AsyncUDP` входят в него; I2Cdevlib для этой прошивки не требуется.

Откройте в Arduino IDE файл `MPU6500_with_TCA9548A_udp.ino` и выберите свою
плату ESP32-C3/C6. Файлы `MahonyFilter.h/.cpp` должны оставаться в том же
каталоге: Arduino соберёт и подключит их автоматически.

Логику фильтра можно проверить на компьютере независимо от Arduino:

```bash
g++ -std=c++17 -Wall -Wextra -Werror \
  tools/benchmarks/mpu_gravity/test_mahony_filter.cpp \
  sensors/esp32/MPU6500_with_TCA9548A_udp/MahonyFilter.cpp \
  -o /tmp/test_mahony_filter
/tmp/test_mahony_filter
```

После загрузки откройте Serial Monitor на скорости 115200 бод. Для каждого
исправного датчика ожидается строка вида:

```text
OK:S2 MPU6500 filter=Mahony calibration=loaded
```

Если вместо `0x70` обнаружен другой `WHO_AM_I`, канал не переходит в
состояние `ready`.

## UDP-протокол

Один кадр передаётся одной UDP-датаграммой:

```text
FRAME <sequence> <millis> <quaternion_count>
Q <tca_channel> <w> <x> <y> <z>
Q <tca_channel> <w> <x> <y> <z>
```

Компоненты кватерниона передаются в порядке `w x y z`. Формат совместим с
прошивкой MPU-6050 и текущим приложением `host/viz/pyqt_mocap`.

## Команды

Команды принимаются по UDP и через Serial:

| Команда | Назначение |
|---|---|
| `HELLO` | зарегистрировать UDP-клиента |
| `PING` | проверить доступность контроллера |
| `START` | начать передачу кадров |
| `STOP` | остановить передачу кадров |
| `STATUS` | получить состояние датчиков и счётчики |
| `GET_CONFIG` | получить ту же конфигурационную информацию |
| `SET_RATE <1..100>` | изменить частоту UDP-кадров |
| `CALIB_GYRO` | измерить и сохранить смещения гироскопов |
| `CALIB` | измерить и сохранить смещения акселерометров и гироскопов |

Ответы начинаются с `ACK`, `PONG`, `STATUS`, `SENSOR` или `ERR`.
В ответе `STATUS` эта версия дополнительно сообщает
`filter=mahony filter_hz=100`, а строки датчиков содержат
`dmp=0 filter=1 whoami=0x70`.

## Калибровка

Автоматической калибровки при включении нет: надетые датчики имеют разные
ориентации, поэтому текущую позу нельзя принимать за горизонт.

Перед первым использованием выполните полную калибровку:

1. Снимите все датчики с человека.
2. Положите их неподвижно одной и той же стороной, локальной осью Z вверх.
3. Отправьте `CALIB` и не трогайте датчики примерно 3–4 секунды.
4. Дождитесь `ACK CALIB DONE`.

Прошивка усредняет по 300 отсчётов каждого датчика, вычисляет смещения
акселерометра и гироскопа и сохраняет их в NVS ESP32 отдельно для каждого
канала TCA. Если физические датчики переставлены между каналами, выполните
`CALIB` заново.

После надевания системы можно выполнить `CALIB_GYRO`: человек и все датчики
должны оставаться неподвижными примерно 3–4 секунды. Эта команда обновляет
только смещения гироскопов и сохраняет ранее измеренную калибровку
акселерометров.

## Как работает ориентация

Фильтр объединяет угловую скорость гироскопа с измеренным направлением силы
тяжести. Коррекция по акселерометру ослабляется при линейном ускорении: её вес
плавно уменьшается до нуля, если модуль ускорения отклоняется от 1 g на
0,25 g или больше. Поэтому быстрый взмах руки не должен заставлять фильтр
считать линейное ускорение новым направлением вертикали.

MPU-6500 не содержит магнитометра. Наклон относительно гравитации наблюдаем,
но абсолютный курс вокруг вертикальной оси со временем может дрейфовать.

## Быстрая проверка

1. Отправьте `HELLO`, затем `STATUS`.
2. Убедитесь, что нужные каналы имеют
   `ready=1 whoami=0x70 calibrated=1`.
3. Отправьте `START` и проверьте наличие строк `FRAME` и `Q`.
4. Медленно переверните один датчик локальной осью Z вниз и удерживайте его.
   Направление руки/куба должно остаться перевёрнутым, а не возвращаться к
   исходному положению.
