# Прошивки ESP32

В этой папке находятся две прошивки для разных этапов работы с системой из
ESP32, мультиплексора TCA9548A и датчиков MPU6050. Одновременно на контроллер
загружается только одна из них.

## `DMP_with_TCA9548A_udp/`

Основная прошивка системы захвата движений. Она:

- обнаруживает до пяти MPU6050 на каналах TCA9548A;
- получает кватернионы из DMP датчиков;
- принимает команды управления по UDP;
- передаёт один согласованный `FRAME` со всеми доступными кватернионами;
- поддерживает запуск, остановку, калибровку и изменение частоты потока.

Главный скетч — `DMP_with_TCA9548A_10HZ_upd.ino`. Несмотря на историческое
`10HZ` в имени, частота меняется командой `SET_RATE` в диапазоне 1–100 Гц.
Подробное описание протокола и команд находится в README внутри каталога.

Физический маппинг каналов: `7/6` — левая рука, `2` — корпус, `1/0` —
правая рука.

### Настройка Wi-Fi

Реквизиты локальной сети не хранятся в репозитории. Перед сборкой основной
прошивки выполните в её каталоге:

```bash
cp wifi_secrets.example.h wifi_secrets.h
```

Откройте `wifi_secrets.h` и укажите свои значения:

```cpp
static const char *WIFI_SSID = "имя сети";
static const char *WIFI_PASSWORD = "пароль сети";
```

`wifi_secrets.h` добавлен в локальный `.gitignore`. В коммиты должен попадать
только безопасный `wifi_secrets.example.h`.

Для сборки нужны ESP32 Arduino core, `AsyncUDP` и I2Cdevlib с
`MPU6050_6Axis_MotionApps20`.

## `scan_bus_web/`

Диагностическая прошивка для проверки уже собранной системы. Она сканирует
основную I2C-шину, проверяет TCA9548A по адресу `0x70`, а затем последовательно
сканирует все восемь каналов мультиплексора.

Сканер не использует домашнюю или лабораторную Wi-Fi сеть. После загрузки
ESP32 создаёт открытую временную точку доступа:

```text
ESP32C3_I2C
```

Порядок проверки:

1. Загрузите `scan_bus_web/scan_bus_web.ino` в ESP32.
2. Откройте Serial Monitor на скорости 115200 бод.
3. Подключитесь с компьютера или телефона к сети `ESP32C3_I2C`.
4. Откройте адрес, напечатанный в Serial Monitor. Обычно это
   `http://192.168.4.1`.
5. Нажмите «Сканировать шину» или включите автообновление.

При исправном соединении основная шина должна видеть TCA9548A по адресу
`0x70`. На каждом занятом канале должен обнаруживаться MPU6050, обычно по
адресу `0x68`, реже `0x69`. Пустые каналы выводятся как `NONE`.

Точка доступа открытая, поскольку прошивка предназначена только для временной
стендовой диагностики. После проверки загрузите обратно основную UDP-прошивку.
