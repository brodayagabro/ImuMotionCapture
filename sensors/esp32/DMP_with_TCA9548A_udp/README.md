# ESP32: MPU6050 ×5 через TCA9548A и UDP

Прошивка опрашивает до пяти MPU6050 через мультиплексор TCA9548A, получает
кватернионы из DMP и отправляет синхронизированные кадры по UDP. Целевая плата
— ESP32-C3/C6 с Arduino core.

## Файлы

- `DMP_with_TCA9548A_10HZ_upd.ino` — основной скетч;
- `wifi_secrets.example.h` — безопасный шаблон настроек Wi-Fi;
- `wifi_secrets.h` — локальные реквизиты сети, создаются пользователем и
  игнорируются Git;
- `.gitignore` — исключает локальные настройки и служебные файлы Python.

Несмотря на `10HZ` в историческом имени скетча, рабочая частота настраивается
в диапазоне от 1 до 100 Гц.

## Аппаратная конфигурация

К одной ESP32 подключен TCA9548A, к его каналам — пять MPU6050. Прошивка ищет
адрес мультиплексора в диапазоне `0x70`–`0x77`, а датчики — по адресам `0x68`
и `0x69`. Идентификатор датчика в UDP-пакете равен физическому каналу TCA.

Утвержденный физический маппинг:

| Канал TCA | Сегмент тела | Имя сегмента |
|---:|---|---|
| 7 | левое плечо / верхняя часть руки | `shoulder.L` |
| 6 | левое предплечье | `forearm.L` |
| 2 | корпус / спина | `spine` |
| 1 | правое предплечье | `forearm.R` |
| 0 | правое плечо / верхняя часть руки | `shoulder.R` |

По умолчанию включено автоматическое сканирование всех восьми каналов. Если
`AUTO_DETECT_CHANNELS` отключить, используется список `0, 1, 2, 6, 7`.

## Настройка Wi-Fi

Реквизиты локальной сети в репозитории не хранятся. Перед первой сборкой
создайте приватный заголовок:

```bash
cd sensors/esp32/DMP_with_TCA9548A_udp
cp wifi_secrets.example.h wifi_secrets.h
```

Укажите в `wifi_secrets.h` свою сеть:

```cpp
static const char *WIFI_SSID = "имя сети";
static const char *WIFI_PASSWORD = "пароль сети";
```

Не добавляйте `wifi_secrets.h` в Git. Без этого локального файла основная
прошивка намеренно не собирается.

UDP-сервер слушает порт `4210`. Порт задается константой `UDP_LISTEN_PORT` в
скетче и при необходимости может быть изменен перед сборкой.

## Зависимости и сборка

Для сборки нужны:

- ESP32 Arduino core;
- `Wire`, `WiFi` и `AsyncUDP` из ESP32 core;
- I2Cdevlib;
- `MPU6050_6Axis_MotionApps20`.

После загрузки откройте Serial Monitor на скорости 115200 бод. При старте
прошивка:

1. подключается к Wi-Fi и запускает UDP-сервер;
2. ищет TCA9548A и датчики на его каналах;
3. инициализирует DMP каждого найденного MPU6050;
4. выполняет калибровку акселерометров и гироскопов;
5. ожидает команду от UDP-клиента или через Serial.

## UDP-протокол

Один кадр отправляется одной UDP-датаграммой:

```text
FRAME <sequence> <millis> <quaternion_count>
Q <tca_channel> <w> <x> <y> <z>
Q <tca_channel> <w> <x> <y> <z>
```

Компоненты кватерниона передаются в порядке `w x y z`. UDP не гарантирует
доставку; следующий кадр всегда содержит актуальное состояние обнаруженных
датчиков.

Прошивка запоминает одного активного получателя. Любая корректная UDP-команда
назначает ее отправителя новым получателем потока.

## Команды

| Команда | Назначение |
|---|---|
| `HELLO` | зарегистрировать UDP-клиента |
| `PING` | проверить доступность контроллера |
| `START` | сбросить FIFO и начать поток |
| `STOP` | остановить поток |
| `STATUS` | получить состояние датчиков и счетчики |
| `GET_CONFIG` | получить текущую частоту и сетевые параметры |
| `SET_RATE <1..100>` | изменить частоту кадров |
| `CALIB_GYRO` | откалибровать только гироскопы |
| `CALIB` | откалибровать акселерометры и гироскопы |

Команды принимаются как по UDP, так и через Serial. Ответы начинаются с
`ACK`, `PONG`, `STATUS`, `SENSOR` или `ERR`.

## Калибровка

Во время любой аппаратной калибровки датчики должны быть неподвижны.

- `CALIB_GYRO` допустимо выполнять на надетой системе, если человек полностью
  неподвижен.
- `CALIB` вызывает калибровку акселерометров и гироскопов. Все модули следует
  снять, положить одинаковой стороной и направить их локальную ось Z вверх.

После переподключения датчика, изменения канала TCA или перезагрузки системы
проверьте список `SENSOR` в ответе `STATUS`.

## Ограничения

MPU6050 не содержит магнитометра. Абсолютный курс вокруг вертикальной оси не
наблюдаем и при длительной работе может дрейфовать. Прошивка передает
ориентацию DMP без внешней коррекции курса.
