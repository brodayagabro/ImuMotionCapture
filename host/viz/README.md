# Визуализация данных

В каталоге собраны три независимых варианта визуализации данных с датчиков:

- `pyqt_mocap/` — основное PyQt-приложение для захвата движения, калибровки и
  отображения скелетной модели;
- `cube_viewer/` — лёгкий диагностический Tk/Matplotlib-визуализатор: один
  вращающийся куб на каждый датчик;
- `blender/` — демонстрационная Blender-сцена и сборщик UDP-варианта сцены.

Инструкции по установке и запуску находятся в README каждого модуля.
