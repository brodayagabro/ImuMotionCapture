# Cube Viewer

Диагностическое приложение показывает ориентацию пяти MPU6050 в виде
независимых кубов. Оно принимает кватернионы от ESP32 по UDP, выводит исходные
пакеты и позволяет отправлять команды прошивке.

В отличие от `pyqt_mocap`, этот визуализатор не строит скелет и не выполняет
анатомическую калибровку. Он нужен для быстрой проверки связи, порядка датчиков
и корректности кватернионов.

## Возможности

- пять независимо вращающихся кубов;
- назначение номера датчика каждому кубу в интерфейсе;
- поддержка физических каналов TCA9548A `0, 1, 2, 6, 7`;
- совместимость со старой последовательной нумерацией `1..5`;
- монитор входящих UDP-пакетов;
- команды `START`, `STOP`, `STATUS`, `CALIB` и `SET_RATE`;
- произвольные ASCII-команды.

## Запуск

Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m cube_viewer
```

Установка также добавляет консольную команду `cube-viewer`.

Также можно запустить файл напрямую:

```bash
python host/viz/cube_viewer/mpu_udp_viewer_tk.py
```

Tkinter входит в стандартную библиотеку Python, но в некоторых Linux-системах
его пакет нужно установить отдельно (например, `python3-tk`).

В окне укажите актуальный IP-адрес ESP32 и UDP-порт прошивки (по умолчанию
`4210`), затем нажмите «Подключиться». Приложение откроет локальный UDP-сокет и
отправит `HELLO`, после чего прошивка начнёт присылать данные этому клиенту.
